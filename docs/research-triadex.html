_research/Triadex Muse

A SuperCollider reimplementation of the Triadex Muse (1969) — the algorithmic music composer designed by Edward Fredkin and Marvin Minsky at MIT. Deterministic melodic sequences from binary logic.

_about

The Triadex Muse was a digital algorithmic music composer, not a synthesizer in the traditional sense. It generated melodies from deterministic processes using digital logic: a handful of binary counters, a 31-bit linear feedback shift register (LFSR), and an XNOR gate produce patterns that scale, riff, call-and-respond, and develop thematically. All the hallmarks of real musical composition, emerging from simple binary logic. No randomness, no pre-programmed sequences. Only about 280 units were ever built.

The original hardware operated at the level of resistor networks and voltage dividers. The INTERVAL section's four binary sources (A, B, C, D) selected voltages that, combined through a resistor ladder, produced one of eight discrete voltage levels fed to a divide-down oscillator. The three least significant bits (A, B, C) addressed eight notes of a major scale; the fourth bit (D) shifted the result up one octave. Pitch was not frequency in any abstract sense — it was a physical ratio determined by component values. The instrument thought in integers: 3-bit addresses into a fixed voltage table.

Reimplementing this in SuperCollider means translating from resistors to integers to floats. The 3-bit value (0-7) that once selected a resistor tap now indexes into a scale array — and because the array is programmable, the instrument is no longer bound to the major scale. Any tuning system becomes available: chromatic, microtonal, just intonation, Fokker's 31-TET, arbitrary frequency tables. The octave bit generalises to any interval multiplication. What was a hardware constraint becomes a compositional parameter. The deterministic logic that generates the sequences remains identical; what changes is the mapping from integer to pitch, from address to frequency. J. Donald Tillman's JavaScript emulation was a key reference for understanding these internal mappings.

This project is a faithful reimplementation in SuperCollider, preserving the original architecture while extending it with programmable scales, multi-voice capability, pattern integration, and a light show visualisation derived from the shift register state. The implementation follows a media-archaeological approach: reconstructing the instrument's logic from patent documentation (US 3,610,801) and the original programming manual. The core engine is decoupled from audio output, allowing the deterministic note sequences to drive any synthesis method, MIDI output, or SC pattern infrastructure.
